# ITSTEPMarket — Інтернет-магазин техніки та гаджетів

Екзаменаційний проект на React 19 + React Router v7.

## Реалізований функціонал

### 1. Сторінка товару
- Маршрут `/product/:id` з динамічним відображенням даних.
- Перехід до товару за кліком на картку або кнопку з каталогу та з таблиці адмін-панелі.
- Повна інформація: категорія, назва, ціна / стара ціна, детальний опис, таблиця характеристик, вибір кількості та статус наявності.

### 2. Кошик товарів
- Додавання товарів з каталогу або сторінки товару.
- При повторному додаванні кількість товару автоматично збільшується.
- Окрема сторінка кошика `/cart` зі списком товарів, промокодами (`TECH10` для знижки 10%) та модальним вікном оформлення замовлення.

### 3. Операції з кошиком
- Зміна кількості одиниць для кожного товару (+ / -).
- Видалення конкретного товару або повне очищення кошика.
- Автоматичний розрахунок загальної вартості, знижок та підсумку до сплати.

### 4. Збереження стану (Persistence)
- Стан кошика та стан каталогу товарів синхронізуються з `localStorage`.
- Додані або відредаговані адміністратором товари зберігаються між перезавантаженнями сторінки.

### 5. Адміністративна панель
- Сторінка авторизації `/admin/login` (Логін: `admin`, Пароль: `admin123`).
- Захищений маршрут `ProtectedRoute` для панелі `/admin`.
- Повне управління товарами (CRUD): перегляд списку, додавання, редагування та видалення з модальними вікнами підтвердження.
- Контрольовані форми з повною валідацією полів (обов'язкові поля, формат цін, посилань та описів).

## Запуск та збірка

```bash
# Встановлення залежностей
npm install

# Запуск dev-сервера
npm run dev

# Продакшн збірка
npm run build
```

## Деплой на GitHub Pages

```bash
# Збірка та публікація на гілку gh-pages
npm run deploy
```
